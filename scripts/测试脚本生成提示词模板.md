# 使用说明

复制下面「提示词」整段发给大模型。只改【板卡名称】，并按同样一句一条追加测试项目。把返回的 `.sh` 保存后，在 BoardTestTool 里打开即可。

## 提示词

你是嵌入式 Linux 板卡生产测试脚本工程师。请为板卡【板卡名称】生成一份可在 busybox `sh` 上直接运行、并被上位机 BoardTestTool 解析的生产测试脚本。

执行环境（必须遵守）：

- 上位机把脚本 SFTP 到板卡 `/tmp/boardtest_xxx.sh` 后用 **`sh`（busybox ash）** 执行，不是 bash，不要按 Ubuntu bash 写。
- 第一行必须是 `#!/bin/sh`。只写 POSIX / busybox ash 能跑的语法。
- **必须先完整定义 `log`、`json_escape`、`record_result`，再调用它们。** 禁止调用未定义命令。
- 日志函数名只能是 `log`（写 stderr）。记结果函数名只能是 `record_result`。**禁止**自创 `loge`、`record`、`log_err` 等别名。
- 禁止 bashism：`function foo`、`local`、数组（`arr=()` / `${arr[0]}`）、`[[ ]]`、`source`、`declare`、here-string `<<<`、进程替换。
- 禁止 `set -e` / 单项失败 `exit 1`。全部跑完后 stdout 打 JSON，然后 `exit 0`（即使全 fail）。

必须先原样包含下面三函数（可改注释，不可改函数名、不可省略），再写测试逻辑：

```
log() { echo "$@" >&2; }

json_escape() {
    sed -e 's/\\/\\\\/g' -e 's/"/\\"/g' | \
        awk 'BEGIN{ORS=""} { if(NR>1) printf "\\n"; printf "%s", $0 }'
}

ITEMS_JSON=""
record_result() {
    _esc_name="$(printf '%s' "$1" | json_escape)"
    _esc_item="$(printf '%s' "$2" | json_escape)"
    _esc_result="$3"
    _esc_msg="$(printf '%s' "$4" | json_escape)"
    _esc_raw="$(printf '%s' "$5" | json_escape)"
    _obj="$(printf '{"test_name":"%s","test_item":"%s","result":"%s","msg":"%s","raw_log":"%s"}' \
        "$_esc_name" "$_esc_item" "$_esc_result" "$_esc_msg" "$_esc_raw")"
    if [ -z "$ITEMS_JSON" ]; then
        ITEMS_JSON="$_obj"
    else
        ITEMS_JSON="$ITEMS_JSON,$_obj"
    fi
}
```

协议：

- stdout 全程只输出一段纯净 JSON 数组（最后用 `printf '[%s]\n' "$ITEMS_JSON"`）；过程日志、命令输出、错误原因全部走 `log`（stderr）。
- JSON 每项仅含这 5 个字段，禁止自创别名：`test_name`（中文名）、`test_item`（英文唯一 ID）、`result`（仅小写 `pass` 或 `fail`）、`msg`（一两句原因）、`raw_log`（关键日志，须经 `json_escape` 转义）。
- stdout 样例（不要美化缩进、不要夹杂日志）：
  `[{"test_name":"ttyUSB0自发自收测试","test_item":"ttyusb0_loopback","result":"pass","msg":"收发一致","raw_log":"发送: ABC | 接收: ABC"},{"test_name":"ttyUSB1自发自收测试","test_item":"ttyusb1_loopback","result":"fail","msg":"设备不存在: /dev/ttyUSB1","raw_log":"无此节点"}]`
- 自发自收类：设备 `/dev/对应节点`；用 `exec N<>` 打开后 `stty` 配 115200 8N1 raw 无流控关回显；`printf` 写一段固定数据，再用 `timeout` + `dd bs=1 count=N` 读回比对。设备不存在、权限不足、打不开、stty 失败、写入失败、超时未收满、内容不一致，均 `record_result` 记 `fail` 并在 `msg` 写清原因，然后 `return 0` 继续下一项。
- 只输出一份完整 `.sh`，不要 markdown 围栏，不要脚本前后的解释。第一个字符必须是 `#`，最后是 `exit 0`。
